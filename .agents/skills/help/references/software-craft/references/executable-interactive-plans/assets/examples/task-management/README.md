# Task-management executable plan

This version `3.0.0` example starts from `../../story-test-template` with an illustrative current task-domain snapshot and a paired proposal. It narrows `TaskTitle` from 120 to 80 characters, removes `TaskStatus`, replaces it with `Task.completed`, and adds `CompleteTaskInput`, `TaskNotFound`, `TaskServiceShape.complete`, and `completeTask`.

Use the scope board or its keyboard-accessible no-WebGL list to establish those declared and structural effects, then use the exact current/proposed Monaco diff before running the story properties, approving, and exporting the review.

```sh
npm install
npm run dev
```

Open `http://127.0.0.1:4174/`.
