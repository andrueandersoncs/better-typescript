# Informally Verify Moore's Law

Read the law's exact wording and context in [`../reference.md`](../reference.md), then follow the shared [`informal-verification` method](../informal-verification.md).

## Investigation

> Gather dated component-count and cost data across several semiconductor generations. Plot the trend, estimate doubling time, and inspect recent periods for acceleration, slowdown, or a break.
