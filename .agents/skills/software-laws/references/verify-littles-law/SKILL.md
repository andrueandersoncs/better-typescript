# Informally Verify Little's Law

Read the law's exact wording and context in [`../reference.md`](../reference.md), then follow the shared [`informal-verification` method](../informal-verification.md).

## Investigation

> Select a queue with consistent boundaries. Calculate average work in progress, completion rate, and average time in the system using matching units. Compare observed `L` with `λW` across several sufficiently long periods.
