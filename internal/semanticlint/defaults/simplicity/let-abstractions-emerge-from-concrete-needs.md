# Let abstractions emerge from concrete needs

Make every function, class, interface, and module clarify intent, enforce a boundary, isolate an external system, support real variation, or remove meaningful repetition. Avoid wrappers that merely rename or forward an operation, and do not create an interface and factory for every class merely to make the code look modular.
