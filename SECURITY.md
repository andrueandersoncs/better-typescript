# Security Policy

## Supported version

Only the latest commit on `main` is supported. Older commits and releases are not supported.

## Reporting a vulnerability

Do not open a public issue with vulnerability details. If GitHub private vulnerability reporting is
available, use the repository's **Security** tab to open a private security advisory.

If private reporting is unavailable, open an issue asking for a private contact method. Do not include
vulnerability details in that issue.

This project has no response or resolution SLA.
